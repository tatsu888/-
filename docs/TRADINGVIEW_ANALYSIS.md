# TradingView 機能分析と実装状況

> この分析は、TradingView の公開されている機能（2026 年時点の一般的な仕様）についての知識をもとに作成しています。開発環境から tradingview.com に接続できなかったため、実際の画面と照合した検証はしていません。抜けていた機能は追記してください。

凡例：✅ 実装済み ／ 🟡 一部実装 ／ ⬜ 未実装（ROADMAP 行き）

## 1. チャート

| TradingView の機能 | 状態 | 本ツールでの実装 |
|---|---|---|
| 足種：ローソク、バー、ライン、エリア、平均足 | ✅ | GP の CANDLE / BAR / LINE / AREA / HA |
| 足種：Renko、カギ足、ポイント＆フィギュア、出来高ローソク | ⬜ | |
| 時間足：1 分〜月足 | ✅ | 1, 5, 15, 30 分、1H, 4H, D, W, M |
| 秒足、任意の時間足 | ⬜ | |
| 対数軸 | ✅ | LOG |
| パーセント軸・比較チャート | ✅ | COMPARE（複数銘柄。自動で % 表示に切替） |
| クロスヘア、OHLCV 凡例 | ✅ | |
| 出来高 | ✅ | VOL |
| インジケーター（SMA, EMA, BB, VWAP, RSI, MACD） | ✅ | 別ペイン（RSI, MACD）に対応 |
| ATR、ストキャスティクス、一目均衡表、出来高プロファイル | 🟡 | ATR とストキャスはサーバー側（TA）に実装。チャート上への表示は ⬜ |
| Pine Script（ユーザー定義インジケーター） | ⬜ | 代わりに Python の analytics を拡張する方針 |
| 描画：水平線、トレンドライン、フィボナッチ・リトレースメント | ✅ | 銘柄ごとに localStorage へ保存 |
| 描画：平行チャネル、図形、テキスト、ピッチフォーク、価格帯の計測 | ⬜ | |
| マルチチャートレイアウト | ✅ | 1 / 2 / 3 / 4 / 6 分割（どのパネルにも GP を表示可能） |
| バーリプレイ | ⬜ | |
| チャートの画像保存 | ⬜（CSV 出力は ✅） | |

## 2. マーケットデータ・監視

| 機能 | 状態 | 実装 |
|---|---|---|
| ウォッチリスト（複数、並べ替え、ティック時の点滅） | ✅ | W |
| ティッカーテープ | ✅ | |
| 指数、FX、金利、コモディティ、暗号資産の一覧 | ✅ | WEI / FX / RATES / CMDTY / CRYP |
| 銘柄検索 | ✅ | コマンドラインの候補表示 |
| スクリーナー（値上がり・値下がり・出来高・時価総額） | ✅ | MOST |
| スクリーナー（任意条件のフィルタ） | 🟡 | API はスキャナーを使うので拡張は容易。UI は ⬜ |
| ヒートマップ | ✅ | HMAP（時価総額 × 騰落率） |
| 銘柄概要・ファンダメンタルズ・財務 | 🟡 | DES（主要指標とパフォーマンス）。財務諸表の詳細は ⬜ |
| テクニカル判定のゲージ | ✅ | TA（4 つの時間足） |
| ニュース | ✅ | N |
| 経済指標カレンダー | ✅ | ECO |
| 決算カレンダー | ⬜ | |
| アラート（価格、交差、騰落率） | ✅ | ALRT とチャートからの作成。サーバー側で評価し、デスクトップ通知 |
| インジケーター条件のアラート、Webhook | ⬜ | |

## 3. 分析・取引

| 機能 | 状態 | 実装 |
|---|---|---|
| ストラテジーテスター | ✅ | BT（5 戦略、手数料、ロング／ショート、統計、取引一覧） |
| ペーパートレード、ポートフォリオ | 🟡 | PORT（ポジションと損益のみ） |
| 相関 | ✅（TradingView には標準でない） | CORR |
| アイデア投稿、SNS 機能 | ⬜（対象外） | |

## 4. ブルームバーグ風・アナリスト向けの独自機能（TradingView にないもの）

| 機能 | 実装 |
|---|---|
| コマンドライン `<銘柄> <機能> <GO>`、ファンクションキー、パネルの銘柄連動と固定 | ✅ |
| ファクター／スタイル分析 | FACT |
| リード・ラグ（タイムラグ）分析 | LAG |
| 銘柄に紐付いた Excel モデルの参照と What-if | XLS |
| 業績予想ハーネス（決定的、検証付き） | MODEL |
| 銘柄メモ | NOTE |
| データ取得元の手動切替 | SRC とステータスバー |
