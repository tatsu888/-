# ECON — マクロ統計（日本＋海外 約 400 系列）の自動取得・分析・資金フロー（`ECST`）

マクロ投資家が見ている数百の統計を、公式のデータ源から自動で集め、国・分野ごとに束ねて読む。数値はすべて公表値か、それを決まった式で変換したもの（AI は使わない、推測で埋めない）。

## 2. データ源と鍵

| データ源 | 取得方法 | 鍵 |
|---|---|---|
| FRED（セントルイス連銀：BEA・BLS・Census・FRB・地区連銀・ICE BofA・BIS・IMF・OECD の転載） | `fredgraph.csv?id=…`（鍵なし）／鍵があれば API | `FRED_API_KEY`（任意。検索に必要） |
| e-Stat（政府統計の総合窓口：総務省・厚労省・財務省・経産省・国交省・内閣府） | REST API 3.0（JSON） | **`ESTAT_APP_ID`（必須。e-Stat で無料登録）** |
| ECB Data Portal | SDMX（CSV） | なし |
| Eurostat | JSON-stat 2.0 | なし |
| 世界銀行 WDI | JSON | なし |
| DBnomics（IMF・OECD・BIS・各国統計の集約） | JSON（自分で追加する系列用） | なし |
| 市場（TradingView／Yahoo） | ターミナルの価格 | — （**SIM のときは保存しない**） |
| ファイル取り込み | CSV／Excel（財務省 対外対内証券投資・JPX 投資部門別・自分のデータ） | — |

**e-Stat の表は検索で見つける**：e-Stat の表 ID は統計ごとに多数あり、改定で変わることもあるため、カタログには「統計名・政府統計コード・検索語・系列を決める語（例：完全失業率／季節調整）」の手順を書いている。初回は `getStatsList` で表を探し、`getMetaInfo` で各分類から語に合うもの（無ければ「総数・全国・計」）を選び、選んだ表と分類コードを保存して以後はそれで取得する。選ばれた表は SERIES に表示。違っていれば SOURCES の「表を選ぶ」で候補から固定できる（固定は自動で変わらない）。

**コードは開発環境から取得を確認できていない**（クラウド環境の通信制限で全データ源が 403）。識別子は各提供元の公開 ID から書いたが、廃止・変更されたものはユーザーの PC での初回の取得で SOURCES に「エラー」または「更新停止?」として出る。そこから「正しいコード」を入れて直すか、止めるか、検索して置き換える。

## 3. 自動更新

- 起動の約 90 秒後と、その後 **30 分ごと**（ECST → SOURCES で ON/OFF と間隔を変更）に、確認の期限が来た系列だけを取りに行く：日次・週次・月次は 6 時間、四半期 12 時間、年次 48 時間ごと。失敗した系列は 2・4・8…時間（最大 48 時間）と間隔を延ばして再試行。PC を閉じていた間の分は、次に起動したときに取り戻す。
- データ源ごとに同時接続を 2 本に抑え、間隔を空ける（各提供元への負担を小さく）。
- **発表の検出**：前回より新しい期間のデータが入ったら「発表」として記録（最初の取得と日次の系列は数えない）。機械的な AR(1) 予想との差（z）を「サプライズ」として付ける（市場予想ではない）。主要指標の発表は画面に通知。
- 取得後に、合成指数・ヒートマップ・資金フローを計算し直して保存（`data/econ/dashboard.json`・`flows.json`）。朝のブリーフ（BRIEF）はこの結果を読む。
- `TERMINAL_ECON_AUTO=0` で自動更新を止める（テストで使用）。

## 4. 分析

| 項目 | 定義 |
|---|---|
| シグナル | 系列ごとに決めた変換：前年比 %（水準の系列）、そのまま（金利・率・DI）、前期差（雇用者数）、前年差 |
| z | シグナルの直近値の z（約 5 年）。10 年の中の位置（パーセンタイル） |
| 傾向 | 直近 3 期の平均 − 12 期の平均を「良い方向」（`good`：失業率・スプレッドなどは反転）で改善／悪化 |
| 更新停止? | 最新のデータが古すぎる（日次 10 日、週次 21 日、月次 80 日、四半期 200 日、年次 640 日を超える） |
| 合成指数 | 国 × {成長＝生産・消費・住宅・投資・貿易・マインド・雇用／インフレ＝物価・賃金／流動性＝マネー・信用・中銀資産・金融環境}。各系列の月次シグナルを**その時点までの 10 年で z 化**し、良い方向に符号をそろえて平均。発表のずれは前の値で補う（月次 2 か月、四半期 5 か月、年次 14 か月まで）。3 系列以上ある国だけ。世界＝米・ユーロ圏・日・中の平均 |
| 改善の割合（ディフュージョン） | 3 か月前よりシグナルが良い方向に動いた系列の割合 |
| 統計版の成長 × 流動性 | 成長と流動性の合成指数で 4 象限（Trinity 第 3 部。市場データ版は GLQ）。GLQ の下にも表示 |
| サプライズ指数 | 国ごとに、直近 3 か月の発表の AR(1) サプライズ（良い方向に符号調整）の平均 |
| ヒートマップ | 国 × 分野の、最新値の z（良い方向）の平均。更新停止の系列は除く |
| 局面別リターン | 指標の状態（5 年の中央値より高い／低い × 3 か月前より上昇／低下）ごとに、資産（TOPIX・S&P 500・ドル円・金利・金・銅など）のその後 1・3・6 か月のリターン。状態は**発表のずれを考慮し、当時分かっていた情報だけ**で判定 |
| 先行性 | 指標の 3 か月変化と、k か月後の 1 か月リターンの相関（k = 0〜12）。最大のもの（観測 24 以上） |

## 5. 資金フロー（FLOWS）

統計から「お金の流れ」を見る。残高の統計は**変化（Δ）**、ネット購入などフローの統計は**合計**。

| グループ | 系列 | 合計（ドル換算） |
|---|---|---|
| 中銀の流動性 | FRB 総資産、TGA（増加＝吸収）、リバースレポ（増加＝吸収）、準備預金、日銀総資産、ユーロシステム総資産、米ネット流動性、FRB の国債保有 | FRB − TGA − リバースレポ ＋ 日銀 ＋ ECB（重複する準備預金・ネット流動性・国債保有は合計に入れない） |
| マネー・銀行信用 | 米 M2・銀行貸出・商工業貸出・預金・消費者信用、日本 M2・貸出、中国 M2 | 米日中の M2（ドル換算） |
| 現金待機（MMF） | 個人向け・機関投資家向け MMF 残高（増加＝リスク資産からの退避） | 合計 |
| 国際資本フロー | 海外投資家の米国債保有、在米海外銀行の預金、日本の対内・対外証券投資（株式・中長期債）、経常収支 | — |
| 投資部門別（日本株） | JPX の投資部門別売買状況（海外投資家・個人・信託銀行・事業法人…）をファイルで取り込む | — |

各系列：直近の期・短期／中期／1 年の合計、z、連続（流入 n 期／流出 n 期）、累積の推移。ドル換算はその日の為替（ドル円・ユーロドル・ドル人民元）で、単位が分かる系列だけ。

**ファイル取り込み**（SOURCES）：財務省「対外及び対内証券売買契約等の状況」（週次 CSV）、JPX「投資部門別売買状況」、自分の CSV／Excel。日付の列（`2026年1月4日～1月10日` のような範囲は終わりの日）と数値の列を自動で見つけ、列ごとに id・名前・頻度・単位・フローかどうか・通貨への倍率を決めて取り込む。同じ id で取り込み直すと追記・更新し、新しい期間は「発表」として記録する。

## 6. 系列を足す・直す

- **検索して追加**：FRED（鍵が必要）、e-Stat。
- **自分の系列**：`POST /api/econ/custom`（FRED・e-Stat の手順・ECB・Eurostat・世界銀行・DBnomics・市場）。
- **コードを直す／止める**：SOURCES のエラー一覧、または `PUT /api/econ/override/{id}`（`code`、`resolved`＝e-Stat の表の固定、`disabled`、`clear`）。
- **取得テスト**：`POST /api/econ/test`（保存しない）。

## 7. データ

`data/econ/series/<id>.json`（観測値・状態・指標・e-Stat の選んだ表）、`state.json`（発表の記録 3000 件、最終更新）、`dashboard.json`、`flows.json`、`uploads/`。日次は 1990 年以降を保存。

## 8. コード

`backend/app/econ/catalog.py`（一覧）、`sources.py`（データ源：解析は純関数）、`analysis.py`（変換・指標・合成・象限・サプライズ・局面・フロー）、`backend/app/api_econ.py`（取得・保存・自動更新・発表・合成系列・API）、`frontend/src/functions/Econ.tsx`（ECST）。テスト：`test_econ_sources.py`（各提供元の応答の形）、`test_econ_analysis.py`、`test_econ_api.py`。

出典の表示：FRED（Federal Reserve Bank of St. Louis）、政府統計総合窓口（e-Stat）、ECB、Eurostat、World Bank、DBnomics。「このサービスは、政府統計総合窓口(e-Stat)のAPI機能を使用していますが、サービスの内容は国によって保証されたものではありません。」
