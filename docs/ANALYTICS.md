# ANALYTICS — 分析手法の定義と注意点

すべて純 Python で書いた決定的な計算です（`backend/app/analytics.py`, `factors.py`, `leadlag.py`, `stats.py`）。テストは `backend/tests/` にあります。

## 1. ファクター分析（FACT）

### 1-a. ETF プロキシ（`/api/analytics/factors/etf?set=US|JP|SECTORS_US`）

- 各ファクター ETF の超過リターン（ETF のリターン − ベンチマークのリターン、%pt）を、1W(5)、1M(21)、3M(63)、6M(126)、1Y(252) の営業日と YTD で計算します。
- 相対強度（RS）カーブは「ETF ÷ ベンチマーク」を開始時点 100 として正規化したものです。右肩上がりなら、そのスタイルが優位です。
- 日付（UTC）が一致する日だけで揃えます。
- セットの定義は `factors.py` の `FACTOR_SETS` です。US は MTUM, VLUE, QUAL, USMV, IWM, IWF, IWD, VYM, SPHB, SPLV, RSP（ベンチマークは SPY）。JP は 1321, 1489, 1591, 2516（ベンチマークは 1306）。SECTORS_US は XL* と SMH です。
- 利点：TradingView でも Yahoo でも動き、投資可能なリターンに基づいています。欠点：ETF の構成やコストの影響を受け、日本向けの選択肢が少ないことです。

### 1-b. クロスセクション（`/api/analytics/factors/cross_section?market=america|japan|…`）

- TradingView のスキャナーで、時価総額の上位 N 銘柄（既定 500、時価総額 10 億以上、株式のみ）を取得します。
- 各ファクターのスコア（大きいほどそのファクターへのエクスポージャーが高い）：
  - Value (E/P) = 1/PE、Value (B/P) = 1/PB
  - Small Size = −log(時価総額)
  - Momentum 12-1 = (1+1 年リターン)/(1+1 か月リターン) − 1（直近 1 か月を除いたモメンタム）
  - Quality = ROE、Profitability = 粗利率
  - Low Beta = −β（1 年）
  - Dividend Yield = 配当利回り
- 期間 w（1W, 1M, 3M）ごとに、次を計算します。
  - **上位と下位の差**：スコアの上位 20% の平均リターン − 下位 20% の平均リターン（%pt）
  - **IC**：スコアと期間リターンのスピアマン順位相関
- **セクターローテーション**：セクターごとの単純平均リターンです。
- ⚠ **注意**：スコアは「現時点」の値、リターンは「過去」の値です。これは最近勝った銘柄の特徴を説明する（スタイル要因の分解）ためのもので、売買可能なバックテストではありません。Momentum 12-1 と 1M リターンは期間が重ならないよう設計していますが、3M とは一部重なります。

## 2. リード・ラグ分析（LAG）

### データの揃え方

- 日足の終値から対数リターンを計算し、**UTC の日付をキーに、両方が取引した日だけで揃えます**。
- ラグ +k は「先行側の t−k 日目と追随側の t 日目」を比べることを意味します。つまり**先行側が k 営業日先に動く**ということです。
- 東京市場は NY より先に引けるため、米国の D 日の値動きは日本の D+1 日に反映されます。**米国→日本の効果はラグ +1 に現れる**のが自然です。逆向きでラグ 0 に強い相関が出る場合は、同じ日に共通の要因で動いていることを示します。

### 指標

| 指標 | 定義 | 読み方 |
|---|---|---|
| CCF | corr(X_{t−k}, Y_t)、k = −L..L | ±2/√N の帯を超えれば有意（5% 水準の目安） |
| 最も強い先行ラグ | k > 0 の中で \|corr\| が最大のラグ | |
| グレンジャー検定 | 制約あり：Y_t ~ c + ΣY_{t−i}、制約なし：+ ΣX_{t−i}。F = ((RSS_r−RSS_u)/p)/(RSS_u/(n−2p−1)) | p < 0.05 なら「X の過去が Y の予測に役立つ」 |
| 逆方向のグレンジャー | Y → X（ラグ 1） | 両方向とも有意なら、共通の要因やフィードバックの可能性 |
| ローリング相関 | 最も強いラグでの 60 日ローリング相関 | 関係が安定しているか、レジームが変わったか |
| 市場ベータの除去（RESIDUAL） | 追随側について Y − α − β·市場 を OLS で求める | 「TOPIX 全体の動き」を除いた、テーマ固有の波及を見る |

### テーマのプリセット（`leadlag.py` の `THEMES`）

米国半導体 → 日本の半導体、NVIDIA → 日本の AI サプライチェーン、原油 → エネルギーと空運（空運は負の相関を想定）、米 10 年金利 → 日本の金融株、ドル円 → 日本の輸出株、銅 → 非鉄、S&P 500 → 日本の指数、ビットコイン → 暗号資産関連株。

### 注意点

- 相関は因果を意味しません。グレンジャー検定も「予測に役立つか」を見るだけです。
- 複数の銘柄とラグを同時に検定すると、偶然に有意になるものが出ます（多重検定）。テーマのスキャンは仮説を探すためのもので、結論を出すものではありません。
- 金利の記号（例：US10Y）は利回りの水準なので、対数リターンは「利回りの変化率」になります。

## 3. 相関（CORR）

対数リターンのピアソン相関です（全銘柄に共通する時刻のみ）。ボラティリティは 1 本あたりの標準偏差です。

## 4. バックテスト（BT）

- 足の終値でシグナルを出し、**次の足のリターンに適用します（先読みなし）**。
- 手数料：ポジションが 1 単位変わるごとに `fee_bps` を差し引きます。
- 戦略：
  - sma_cross / ema_cross（fast > slow で買い、逆は売りまたはノーポジション）
  - rsi_reversion（下限を割ったら買い、上限を超えたら売り、50 に戻ったら手仕舞い）
  - breakout（過去 N 本の高値・安値を抜けたら）
  - buy_hold
- 統計：トータルリターン、バイ＆ホールド、CAGR、最大ドローダウン、シャープレシオ（年率換算は時間足に応じた本数）、取引回数、勝率、ポジション保有率

## 5. テクニカル判定（TA）

- MA の投票：SMA と EMA の 10, 20, 30, 50, 100, 200 について、価格が MA より上なら +1、下なら −1。
- オシレーター：RSI(14)（30 未満で +1、70 超で −1）、MACD（シグナル線より上で +1）、ストキャスティクス、モメンタム(10)。
- スコア = (MA の平均 + オシレーターの平均)/2。判定は >0.5 で STRONG BUY、>0.1 で BUY、±0.1 以内で NEUTRAL、それ未満で SELL、−0.5 未満で STRONG SELL。TradingView の「テクニカル」ゲージと考え方は同じですが、同一の値にはなりません。
