# ANALYTICS — 分析手法の定義と注意点

すべて純 Python で書いた決定的な計算です（`backend/app/analytics.py`, `factors.py`, `leadlag.py`, `stats.py`）。テストは `backend/tests/` にあります。

## 1. ファクター分析（FACT）

### 1-a. ETF プロキシ（`/api/analytics/factors/etf?set=US|JP|SECTORS_US`）

- 各ファクター ETF の超過リターン（ETF のリターン − ベンチマークのリターン、%pt）を、1W(5)、1M(21)、3M(63)、6M(126)、1Y(252) の営業日と YTD で計算します。
- 相対強度（RS）カーブは「ETF ÷ ベンチマーク」を開始時点 100 として正規化したものです。右肩上がりなら、そのスタイルが優位です。
- 日付（UTC）が一致する日だけで揃えます。
- セットの定義は `factors.py` の `FACTOR_SETS` です。US は MTUM, VLUE, QUAL, USMV, IWM, IWF, IWD, VYM, SPHB, SPLV, RSP（ベンチマークは SPY）。JP は 1321, 1489, 1591, 2516（ベンチマークは 1306）。SECTORS_US は XL* と SMH です。
- 利点：TradingView でも Yahoo でも動き、投資可能なリターンに基づいています。欠点：ETF の構成やコストの影響を受け、日本向けの選択肢が少ないことです。

### 1-b. クロスセクション（`/api/analytics/factors/cross_section?market=america|japan|…`）

- TradingView のスキャナーで、時価総額の上位 N 銘柄（既定 500、時価総額 10 億以上、株式のみ）を取得します。
- 各ファクターのスコア（大きいほどそのファクターへのエクスポージャーが高い）：
  - Value (E/P) = 1/PE、Value (B/P) = 1/PB
  - Small Size = −log(時価総額)
  - Momentum 12-1 = (1+1 年リターン)/(1+1 か月リターン) − 1（直近 1 か月を除いたモメンタム）
  - Quality = ROE、Profitability = 粗利率
  - Low Beta = −β（1 年）
  - Dividend Yield = 配当利回り
- 期間 w（1W, 1M, 3M）ごとに、次を計算します。
  - **上位と下位の差**：スコアの上位 20% の平均リターン − 下位 20% の平均リターン（%pt）
  - **IC**：スコアと期間リターンのスピアマン順位相関
- **セクターローテーション**：セクターごとの単純平均リターンです。
- ⚠ **注意**：スコアは「現時点」の値、リターンは「過去」の値です。これは最近勝った銘柄の特徴を説明する（スタイル要因の分解）ためのもので、売買可能なバックテストではありません。Momentum 12-1 と 1M リターンは期間が重ならないよう設計していますが、3M とは一部重なります。

## 2. リード・ラグ分析（LAG）

### データの揃え方

- 日足の終値から対数リターンを計算し、**UTC の日付をキーに、両方が取引した日だけで揃えます**。
- ラグ +k は「先行側の t−k 日目と追随側の t 日目」を比べることを意味します。つまり**先行側が k 営業日先に動く**ということです。
- 東京市場は NY より先に引けるため、米国の D 日の値動きは日本の D+1 日に反映されます。**米国→日本の効果はラグ +1 に現れる**のが自然です。逆向きでラグ 0 に強い相関が出る場合は、同じ日に共通の要因で動いていることを示します。

### 指標

| 指標 | 定義 | 読み方 |
|---|---|---|
| CCF | corr(X_{t−k}, Y_t)、k = −L..L | ±2/√N の帯を超えれば有意（5% 水準の目安） |
| 最も強い先行ラグ | k > 0 の中で \|corr\| が最大のラグ | |
| グレンジャー検定 | 制約あり：Y_t ~ c + ΣY_{t−i}、制約なし：+ ΣX_{t−i}。F = ((RSS_r−RSS_u)/p)/(RSS_u/(n−2p−1)) | p < 0.05 なら「X の過去が Y の予測に役立つ」 |
| 逆方向のグレンジャー | Y → X（ラグ 1） | 両方向とも有意なら、共通の要因やフィードバックの可能性 |
| ローリング相関 | 最も強いラグでの 60 日ローリング相関 | 関係が安定しているか、レジームが変わったか |
| 市場ベータの除去（RESIDUAL） | 追随側について Y − α − β·市場 を OLS で求める | 「TOPIX 全体の動き」を除いた、テーマ固有の波及を見る |

### テーマのプリセット（`leadlag.py` の `THEMES`）

米国半導体 → 日本の半導体、NVIDIA → 日本の AI サプライチェーン、原油 → エネルギーと空運（空運は負の相関を想定）、米 10 年金利 → 日本の金融株、ドル円 → 日本の輸出株、銅 → 非鉄、S&P 500 → 日本の指数、ビットコイン → 暗号資産関連株。

### 注意点

- 相関は因果を意味しません。グレンジャー検定も「予測に役立つか」を見るだけです。
- 複数の銘柄とラグを同時に検定すると、偶然に有意になるものが出ます（多重検定）。テーマのスキャンは仮説を探すためのもので、結論を出すものではありません。
- 金利の記号（例：US10Y）は利回りの水準なので、対数リターンは「利回りの変化率」になります。

## 3. 相関（CORR）

対数リターンのピアソン相関です（全銘柄に共通する時刻のみ）。ボラティリティは 1 本あたりの標準偏差です。

## 4. バックテスト（BT）

- 足の終値でシグナルを出し、**次の足のリターンに適用します（先読みなし）**。
- 手数料：ポジションが 1 単位変わるごとに `fee_bps` を差し引きます。
- 戦略：
  - sma_cross / ema_cross（fast > slow で買い、逆は売りまたはノーポジション）
  - rsi_reversion（下限を割ったら買い、上限を超えたら売り、50 に戻ったら手仕舞い）
  - breakout（過去 N 本の高値・安値を抜けたら）
  - buy_hold
- 統計：トータルリターン、バイ＆ホールド、CAGR、最大ドローダウン、シャープレシオ（年率換算は時間足に応じた本数）、取引回数、勝率、ポジション保有率

## 5. テクニカル判定（TA）

- MA の投票：SMA と EMA の 10, 20, 30, 50, 100, 200 について、価格が MA より上なら +1、下なら −1。
- オシレーター：RSI(14)（30 未満で +1、70 超で −1）、MACD（シグナル線より上で +1）、ストキャスティクス、モメンタム(10)。
- スコア = (MA の平均 + オシレーターの平均)/2。判定は >0.5 で STRONG BUY、>0.1 で BUY、±0.1 以内で NEUTRAL、それ未満で SELL、−0.5 未満で STRONG SELL。TradingView の「テクニカル」ゲージと考え方は同じですが、同一の値にはなりません。

## 6. 回帰ベータ（BETA、`quant.beta_regression`）

- 日付が一致するリターン（単純リターン）で、r_sec = α + β·r_bmk + ε を OLS で推定します。
- 調整後ベータ = 0.67·β + 0.33（Blume の調整。ブルームバーグの Adj Beta と同じ考え方）。
- α の年率換算は (1+α)^(年間の本数) − 1 です。p 値は t 分布（自由度 n−2）から求めます。
- 残差ボラティリティ（年率）は固有リスクの大きさです。

## 7. ペアスプレッド（SPRD、`quant.pair_spread`）

- ヘッジ比率 h：ln A = c + h·ln B + e を OLS で推定します（全期間）。スプレッド s = ln A − h·ln B − c。
- **エングル・グレンジャー検定**：s について ADF 回帰 Δs_t = a + b·s_{t−1} + γ·Δs_{t−1} を行い、b の t 値を、2 変数・定数ありの臨界値（1%: −3.90、5%: −3.34、10%: −3.04、MacKinnon）と比べます。臨界値より小さければ共和分ありです。
- **半減期**：Δs_t = a + b·s_{t−1} から HL = −ln2 / ln(1+b) 日。b ≥ 0 なら平均回帰しないので表示しません。
- **z スコア**：直近 N 日の平均と標準偏差で標準化した値です。|z| ≥ エントリー閾値で機械的なシグナルを出しますが、売買の推奨ではありません。
- 注意：全期間で推定したヘッジ比率を過去にも当てはめているため、z スコアには後知恵が含まれます。売買ルールの検証にはローリング推定が必要です（ROADMAP）。

## 8. 季節性（SEAS、`quant.seasonality`）

- 月末の終値から月末の終値までのリターン（%）を、年 × 月の表にします。月ごとに平均、中央値、プラスになった割合、件数、最高、最低を出します。
- 標本は年数分しかないため（10 年なら各月 10 件）、統計的な有意性は低いです。

## 9. イベントスタディ（EVT、`quant.event_study`）

- 0 日目：イベント日以降の最初の取引日です。
- マーケットモデル：推定期間 [0 日目 − pre − 10 − 推定期間, 0 日目 − pre − 10) で r = α + β·r_m を推定し、AR_t = r_t − (α + β·r_m,t) とします。
- CAR は [−pre, +post] で AR を累積したものです。イベント全体の平均 CAR と、イベント間の t 値（イベントは独立と仮定）を出します。
- 日付を入れない場合は、|リターン| が 2.5σ を超えた日（最大 30 日）をイベントとみなします。ニュースや決算の代わりとして使うもので、その日の値動き自体を含むので、0 日目の AR は大きくなって当然です。

## 10. ポートフォリオリスク（PORT → RISK、`quant.portfolio_risk`）

- 評価額 = 数量 × 直近の終値 × 為替レート（基準通貨への換算。`FX:USDJPY` など市場慣行どおりのペアを優先）。ウェイトは評価額 ÷ 総エクスポージャー（ショートはマイナス）。
- 共通の取引日（既定 252 日）のリターンからポートフォリオのリターンを作り、ボラティリティ（年率は ×√252）、ヒストリカル VaR（5%・1% 分位点）、ES（それより悪い日の平均）を計算します。金額は総エクスポージャーを掛けたものです。
- リスク寄与度：MCR_i = (Σw)_i / σ_p、寄与 = w_i·MCR_i / σ_p。合計は 100% になります。
- ベータはベンチマークに対する回帰です。ストレステストは、ベンチマークの最悪 5 日にポートフォリオがどう動いたかを示します。
- **制約**：各銘柄のリターンは現地通貨建てで、為替の変動によるリスクは含みません。共通の取引日だけを使うため、休場日の違いで相関は過小評価されがちです。

## 11. 同業他社比較（RV、`quant.peer_stats`）

- 指標ごとに、同業（対象銘柄を含む）の中央値、最小、最大と、対象銘柄のパーセンタイル順位（0 が最小、100 が最大）と、中央値からの乖離率を出します。
- 色は「有利かどうか」を表します。PER・PBR・EV/EBITDA・D/E・β・ボラティリティは低いほど緑、ROE・利益率・配当・リターンは高いほど緑です。

## 12. オプション計算（OV、`frontend/src/lib/options.ts`）

- ブラック・ショールズ・マートン（ヨーロピアン、連続配当利回り q）を使います。Vega は 1 vol ポイントあたり、Theta は 1 日あたり、Rho は金利 1% あたりです。
- IV は二分法で求めます（0.01% から 500% の範囲）。アメリカンタイプの早期行使は扱いません。

## 13. ペアトレードのバックテスト（SPRD、`quant.pair_backtest`）
- ヘッジ比率は過去 `hedge_window` 日の OLS（先読みなし）。スプレッドの z（`z_window`）が `entry_z` を超えたらエントリー、`exit_z` で利確、`stop_z` で損切り。コストは bps で控除。
- 結果はトレード一覧、累積損益、勝率、最大ドローダウン。パラメータを結果を見て選ぶと過学習になる点に注意。

## 14. 周期・フーリエ（CYCL、`fourier.py`）
- 対数線形トレンドを除去 → Hann 窓 → 基数 2 の FFT でピリオドグラム。局所最大のみを周期の候補とする。
- 上位 k 周期で調和回帰（cos/sin、周期 2 は cos のみ）→ 外挿。±2σ は残差の標準偏差から。
- **ローリング・バックテスト**で MAPE をナイーブ（最終値）・ドリフトと比較し、`skill = 1 − MAPE_fourier / MAPE_naive`。価格はランダムウォークに近いので、多くの場合スキルはゼロ付近（画面にも明記）。季節性のある KPI に向く。ハーネスの `fourier` メソッドとしても使える。

## 15. 認識伝播マップ（PROP、`macro.py`）
- 項目ごとに「符号付き z」（方向を揃えた 20 日変化の z）を計算し、資産クラス × 段（1 ニッチ／マクロ専門家、2 マクロ投資家、3 日本の個別株投資家）のタイルに表示。
- 段の合成値どうしのラグ相関（段 1 → 段 3 が何日遅れるか）、**未波及**（上流の |z| ≥ 閾値なのに下流が動いていない項目）、項目ごとの先行指標（上流からのラグ相関の上位）。

## 16. 景気局面と成長 × 流動性（MACRO / GLQ、`macro.regimes`, `macro.growth_liquidity`）
- 成長 × インフレ：成長＝銅/金、インフレ＝TIP/IEF の 3 ヶ月変化の符号で 4 局面。局面は月末に確定し、**翌月**のリターンを集計（先読みなし）。
- 成長 × 流動性（ユーザーの Notion 03.4）：成長＝銅/金・米10年の 63 日変化、流動性＝−DXY・−米2年・HY/IEF の 63 日変化。各成分を過去 756 日で z 化して平均。象限は 1 回復（成長+・流動性+）、2 ピーキング（+・−）、3 スローダウン（−・−）、4 ボトミング（−・+）。直近 20 日の角度変化で回転方向（時計回り＝通常）を判定。象限別の翌 21 日リターンは 21 日おきの重複なしサンプル。**代理指標であり、ユーザー独自の指標ではない**（[FRAMEWORK.md](FRAMEWORK.md) §7）。

## 17. 信用残（MRGN、`margin.py`）
- 信用倍率 = 買残 ÷ 売残。買残 ÷ 20 日平均出来高（返済に何日分の出来高が要るか）。信用倍率の自己分布でのパーセンタイル。
- 信用倍率の変化と 4 週先リターンの相関（8 組以上あるときのみ）。
