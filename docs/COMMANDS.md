# COMMANDS — ターミナル機能一覧

## 入力の文法

```
<SECURITY> <FUNCTION> [args] <GO>    AAPL GP · 7203 DES · NASDAQ:NVDA TA · USDJPY GP · 7203 JP Equity DES
<FUNCTION> [args] <GO>               WEI · MOST JP · LAG oil_energy · FACT JP · FACT xs
<SECURITY> <GO>                      読み込み中の銘柄を変更（固定されていないパネルが追随する）
```

- 銘柄の解釈：`EXCH:TICKER` はそのまま使います。4 桁の数字は `TSE:`、`USDJPY` のような通貨ペアは `FX:`、`BTCUSDT` は `BINANCE:` と解釈します。それ以外は検索 API の最初の候補を使います。
- 「Equity」「Index」「JP」「US」などのブルームバーグ式の補助語は無視します。
- キー操作：どこで入力してもコマンドラインに入ります。↑↓ で候補を選び、Tab で補完、Enter で実行（GO）、Esc で取り消し（CANCEL）です。
- パネル：クリックでフォーカスします（オレンジの枠）。コマンドはフォーカス中のパネルに表示されます。🔗 は読み込み中の銘柄に追随、📌 は固定です。ヘッダーのプルダウンでも機能を切り替えられます。
- 表の行：クリックで銘柄を読み込み、ダブルクリックでチャート（GP）を開きます。
- レイアウト：1 / 2 / 3 / 4 / 6 分割です。配置、銘柄、各機能の状態は localStorage に保存されます。
- **ワークスペース**：`WORKSPACE ▾` で、今の画面配置（パネル、レイアウト、銘柄）に名前を付けて保存・呼び出し・削除できます（例：「朝のチェック」「日本の半導体」「決算」）。保存先はサーバーの store です。
- **コマンド履歴**：コマンドラインが空のときに ↑ / ↓ で過去のコマンド（最大 50 件）を呼び出せます。
- **XLS の範囲操作**：Shift + 矢印または Shift + クリックで範囲を選択し、Ctrl+C でコピー、Ctrl+V で貼り付け（Excel や表計算ソフトからのタブ区切りデータ）、Delete で範囲を消去します。

## 機能一覧

| コード | 名前 | 内容 |
|---|---|---|
| **GP** | チャート | 時間足 1m〜M、CANDLE / BAR / LINE / AREA / HA、LOG、VOL、SMA20/50/200、EMA20、BB、VWAP、一目均衡表、RSI、MACD、Stochastic、ATR、描画（HLINE / TREND / FIB / CLEAR）、ALERT@（クリックした価格でアラート）、COMPARE（% 比較）、CSV、PNG 保存 |
| **DES** | 銘柄概要 | クォート、パフォーマンス（1D〜1Y、YTD、ボラティリティ、52 週レンジ）、ファンダメンタルズ（スキャナー）、紐付いた Excel |
| **TA** | テクニカル判定 | 1H, 4H, D, W のゲージと各指標の投票 |
| **N** | ニュース | 銘柄ニュースと TOP NEWS |
| **XLS** | Excel モデル | 紐付け、表示、**EDIT（HTML から編集し、Excel に保存）**、WHAT-IF（ファイルを変えずに試算）、UNDO、LIVE、Excel で開く、ダウンロード、アップロード。キー操作：矢印・Tab で移動、入力で上書き、Enter・F2 で編集、Delete で消去、Ctrl+Z で元に戻す、Esc で取り消し。[EXCEL.md](EXCEL.md) |
| **NOTE** | メモ | 銘柄ごとのメモ（自動保存） |
| **BT** | バックテスト | sma_cross, ema_cross, rsi_reversion, breakout, buy_hold、手数料、ロング／ショート |
| **BETA** | 回帰ベータ | ベンチマーク（日本株は TOPIX が既定）に対する生ベータ・調整後ベータ、α（年率）と p 値、R²、ボラティリティ、散布図。時間足は 1D / 1W / 1M |
| **SPRD** | ペアスプレッド | `SPRD` でA = 読み込み中の銘柄、B は引数か入力。ヘッジ比率、z スコア、半減期、エングル・グレンジャー検定、機械的なシグナル、**ペアトレードのバックテスト**（ローリング・ヘッジ比率、z のエントリー／エグジット／ストップ）。例：`8306 SPRD TSE:8316` |
| **SEAS** | 季節性 | 年 × 月のリターン表、月別の平均・中央値・勝率、年間リターン |
| **EVT** | イベントスタディ | 日付を入力（決算日など）、空欄なら大きな値動きの日を自動検出。マーケットモデルによる AR と CAR、t 値 |
| **RV** | 同業他社比較 | 同業の銘柄を指定（既定はウォッチリストの同じ取引所の銘柄）。PER、PBR、EV/EBITDA、ROE などと、中央値・パーセンタイル順位 |
| **OV** | オプション計算 | ブラック・ショールズ（配当利回りあり）、グリークス、市場価格からの IV、行使価格ごとの一覧。SPOT ボタンで現在値を入れる |
| **W** | ウォッチリスト | 複数のリスト、追加と削除、並べ替え、点滅表示 |
| **WEI** | 世界株価指数 | 地域別 |
| **FX / RATES / CMDTY / CRYP** | 為替、金利、商品、暗号資産 | |
| **MOST** | スクリーナー | MOST_ACTIVE / GAINERS / LOSERS / LARGEST × 市場 |
| **HMAP** | ヒートマップ | 大きさは時価総額、色は騰落率 |
| **FACT** | ファクター分析 | ETF PROXY（US / JP / SECTORS_US）、CROSS-SECTION（市場別） |
| **LAG** | リード・ラグ | テーマのプリセットまたは任意指定、RESIDUAL、MAX LAG、行をクリックするとペアの詳細 |
| **CORR** | 相関行列 | 銘柄リスト、時間足、期間 |
| **MODEL** | 業績予想ハーネス | LOAD / RUN / SAVE / EXPORT XLSX、RESULT / SPEC / CATALOG。[FORECAST_HARNESS.md](FORECAST_HARNESS.md) |
| **PORT** | ポートフォリオ | POSITIONS：ポジション、評価額、ウェイト、当日損益、含み損益。**RISK**：基準通貨（USD / JPY / EUR）に換算し（為替変動込み）、ボラティリティ、VaR・ES（95/99%）、ベータ、最大ドローダウン、リスク寄与度、ストレステスト。**BLOTTER**：約定の記録、平均取得単価での実現損益、ポジションへの同期 |
| **ALRT** | アラート | 価格の条件 6 種＋指標の条件（RSI の水準、SMA / MACD のクロス、ゴールデン／デッドクロス、出来高急増、高値・安値ブレイク）。サーバー側で評価（価格は毎ティック、指標は毎分）、トーストとデスクトップ通知 |
| **ECO** | 経済指標 | 国、重要度、実績と予想の比較 |
| **EARN** | 決算カレンダー | 次回決算日、残り日数、EPS 予想、前回 EPS、売上予想（TradingView のスクリーナー） |
| **TEAR** | ティアシート | 銘柄1枚のサマリー（価格、パフォーマンス、ファンダメンタルズ、テクニカル、メモ）。印刷・PDF 用のレイアウト |
| **SCRN** | スクリーンビルダー | 条件（PER、ROE、モメンタムなど）を組み立てるスクリーナー。プリセットと保存 |
| **CYCL** | 周期・フーリエ | ピリオドグラム（支配的な周期）、調和回帰による予測、ナイーブ予測とのローリング・バックテスト（スキル） |
| **PROP** | 認識伝播マップ | 資産クラス × 段（ニッチ／マクロ投資家／日本の個別株投資家）のタイル（符号付き z）、段間のラグ相関、**未波及**の検出、先行指標、マップの編集 |
| **MACRO** | マクロ | 金利・カーブ・BEI・クレジット・ボラ・コモディティ、景気局面（成長 × インフレ）と局面別の翌月リターン、**成長 × 流動性 4象限** |
| **MRGN** | 信用残 | JPX の銘柄別信用取引週末残高（CSV / XLSX / URL）を取り込み、信用倍率・買残・売残の推移、株価・出来高との関係、ランキング |
| **TRND** | 関心のトレンド | Google Trends（急騰、関連クエリ、株価との先行性）、X（要 `X_BEARER_TOKEN`）、StockTwits。[ATTENTION.md](ATTENTION.md) |
| **TXT** | 書き起こし分析 | 決算説明会の書き起こし：トーン、前期との言語変化（Lazy Prices）、Q&A の回避度、数字の抽出（出典つき）、出典必須の AI ブリーフ検証。[ATTENTION.md](ATTENTION.md) |
| **SRC** | データソース | TradingView / Yahoo / SIM の状態と切替、**RUN DIAGNOSTICS**（接続の自己診断。結果は AI に貼れる Markdown） |
| **HELP** | ヘルプ | 機能一覧 |

分析系の画面には `SOURCE` 選択欄があり、その分析だけデータ取得元を変えられます（例：長期の日足は Yahoo で取る）。

### 投資の三位一体（ユーザーのフレームワーク）— [FRAMEWORK.md](FRAMEWORK.md)

| コード | 名前 | 内容 |
|---|---|---|
| **TRIN** | 三位一体ハブ | **AUTO（既定）：ルールベースで自動更新する全銘柄の判定（F・M・需給・確信度・サイズ・自動関門・変化のログ）**。手動更新は上部バーの「⟳ 三位一体を更新」。パイプライン（LAYER 1〜4）、読み込み中の銘柄の三位の現在地、裁定ルール。`TRIN SCORE` のようにタブを指定可 |
| **SCORE** | 評点表 | Weight × Score（1〜5）、AI Score、Previous Score → Total、Direction（≥3.4 ロング／≤2.7 ショート）、3.5句、記述ブロック。版を保存 |
| **KELLY** | ケリー | E、F = E/(XW×XL)、成長率 G、六つの原則、推奨ウェイト。評点差→サイズ、保存済み評点からのペア候補 |
| **RULE** | 六層規律 | L1 単一〜L6 ファンドの上限と DD ルールの自動チェック。PORT から取り込み |
| **PAIR** | ペア | Pair Sigma、Pair Correlation、β調整 Net÷Gross、20日スプレッドの入場ルール、ペア適性 4 基準、スプレッド 4 分類 |
| **SHRT** | 空売り8モデル | 8 モデルの条件判定（自動取得＋手入力、不明は不明のまま）、小型株ショート禁止などのガード |
| **CHIP** | 天井／底 | 回転率・信用残・配当利回りによる天井／底シグナル、混雑度 |
| **GATE** | 関門 | アイデアごとの関門①〜⑤と四半期点検Ⅰ〜Ⅳ、毎月リセット |
| **GLQ** | 成長 × 流動性 | 4 象限の現在地、6ヶ月の軌跡、回転方向、次の象限、象限別リターン |
